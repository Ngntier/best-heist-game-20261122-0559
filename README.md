Velvet Vault — a top-down 2D heist game. You are Moth, a thief crossing three rooms of the Galleria Nocturne: the Foyer, the Gallery and the Vault. Each room has patrolling guards with vision cones, sweeping security cameras, a loot target and an alarm meter. Read the patrols, spend your tools (smoke bombs, EMP bursts, lockpicks), grab the treasure and reach the exit before the alarm hits 100. Pure HTML5 canvas, no libraries, no network requests, synthesized WebAudio sounds.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` with any static HTTP server and open `game/index.html`. Move with WASD / arrows (or click the floor), Shift to sneak, E to crack the loot case, 1/2/3 for tools, R to restart.
